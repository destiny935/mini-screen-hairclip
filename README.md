# mini-screen-hairclip
a cute hairclip with a mini display screen that can display messages and graphics! 

## Hardware
- ESP32
- 0.91inch I2C OLED Display Module (mini screen)
- Alomejor Li Poly RC Battery with 600mAh, 1S 30C (Battery)
- 3D-printed hair clip
- button to control display screen

## Features
- Custom pixel-art animations
- Miniature display
- Portable/wearable design

## Repository

- `src/` — ESP32 code
- `artwork/` — Pixel art and animations
- `cad/` — 3D-printable hair clip design
- `images/` — Project photos
